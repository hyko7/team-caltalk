너는 최고의 비즈니스 도메인 전문가야. "Team CalTalk"라는 이름의 팀 단위 캘린더 기반 일정 관리 + 채팅 애플리케이션을 개발하려고 해. business-analyst 서브에이전트를 활용해 다음 내용을 바탕으로 도메인 정의서 초안을 작성해줘.

# 문제 정의

- 팀 일정이 개인 캘린더, 메신저, 엑셀 등에 흩어져 있어 일정 충돌과 누락이 잦다.
- 일정과 대화가 분리되어 있어 변경 맥락을 추적하기 어렵다.
- 팀장이 팀원의 일정을 직접 관리하기 어렵다.

# Team CalTalk 주요 기능

- 월·주·일 단위의 팀 일정 관리
- 팀원 간 팀 일정 공유
- 캘린더와 채팅창을 한 화면에서 보면서 일정 변경
- 팀장은 팀 일정을 추가·수정할 수 있으며, 팀원은 수정할 수 없음
- 팀원은 팀 일정을 조회만 할 수 있으며, 본인 관련 일정 변경이 필요하면 채팅으로 변경을 요청함
- 채팅 이력은 일자별로 저장됨
- 모든 사용자는 로그인 후 기능을 이용함

# 필수 사항

- 도메인 정의서에는 핵심 내용만 포함할 것
- 모든 내용은 한국어로 작성할 것
