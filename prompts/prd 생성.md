# 비즈니스 관련 정보

- 목표 사용자: 학생 및 20대-50대 직장인
- 비즈니스 목표: 1000명이 동시 접속하여 사용할 수 있어야 함

# 기술 제약사항

- 플랫폼 우선순위: 웹 우선, 모바일은 반응형 웹UI로만 고려함.
- 인프라 제약:

* 프론트엔드: React 19 + Typescript + Zustand + Tanstack Query
* 백엔드 : node.js + javascript + express + pg 라이브러리 ( Prisma 사용 금지 )
* 데이터베이스: postgresql 17 사용

# 프로젝트 관리

- 일정: 2일 내에 핵심 기능 완성
- 팀 구성: 1인 개발
- 예산: 1인 개발에 준하는 예산

# 사용자 경험

- 사용자 페르소나: 주 사용자별 상세 시나리오는 생략
- 접근성: 이 앱에서는 고려하지 않음
- 모바일 우선: 반응형 UI만 적용
